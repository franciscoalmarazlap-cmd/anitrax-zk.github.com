ANITRAX redefine las transferencias financieras móviles combinando:

 comunicación peer-to-peer sin internet (Bluetooth)
 ejecución de transacciones registradas en blockchain
 control total mediante inteligencia artificial por voz
 y privacidad avanzada mediante Zero-Knowledge Proofs

El sistema permite que los usuarios realicen y verifiquen operaciones financieras sin revelar datos sensibles, manteniendo integridad criptográfica en cada capa del sistema.

🔐 Core Innovation — Zero-Knowledge Privacy Layer

ANITRAX implementa Zero-Knowledge Proof como capa central de privacidad para transformar un sistema financiero tradicional en un sistema verificable sin exposición de datos.


 ¿Qué protege el ZK en ANITRAX?
 🔒 1. Identidad privada

El usuario puede autenticarse sin revelar:

* nombre
* credenciales
* datos biométricos crudos

Solo se prueba:

> “usuario válido”
💰 2. Fondos sin exposición

Se verifica:

 que el usuario tiene saldo suficiente

Sin mostrar:

* balance total
* historial financiero completo

---

 🤖 3. Acciones del agente IA

El sistema permite:

* ejecutar comandos por voz
* interpretar intenciones financieras

Pero:

* los inputs sensibles del usuario no se exponen públicamente


🔗 4. Integridad de transacciones

Se prueba que:

* la transacción es válida
* no fue manipulada
* cumple reglas del sistema

Sin revelar detalles internos innecesarios

 🤖 ANITRAX AI Agent System

El sistema funciona como un agente inteligente multi-modal:

## Capacidades principales:

* control por voz completo (Speech-to-Action)
* comprensión de lenguaje natural financiero
* ejecución de transferencias automatizadas
* confirmación inteligente de acciones
* respuesta por voz (Text-to-Speech)
* modo accesible sin interacción visual

 ⛓ Blockchain Layer (Ethereum Sepolia)

* Smart Contract Solidity para registro de transacciones
* Guarda: sender, receiver, amount, timestamp, note
* Comunicación directa vía JSON-RPC
* MetaMask Deep Link para firma segura
* Registro de hash + proof ZK en cadena
* Sistema multi-RPC con fallback

 🔵 Peer-to-Peer Bluetooth Layer

* transferencias sin internet
* conexión directa entre dispositivos Android
* envío de payload financiero estructurado
* servicio en segundo plano (Foreground Service)
* reconexión automática y persistente

 🤖 AI Layer (Google Gemini)

* interpretación de comandos complejos
* extracción de intención financiera desde voz
* generación de confirmaciones naturales
* fallback local sin conexión a API
* integración con SpeechRecognizer + TTS

📲 Instalación de ANITRAX

 Requisitos previos

Antes de instalar, asegúrate de tener:

* Android 8.0 o superior (API 26+)
* Bluetooth activado
* MetaMask instalado (para Sepolia)
* Conexión a Internet (solo para blockchain)
* Permitir instalación de apps externas
* Aplicacion de android studio


 Instalación desde código fuente (Android Studio)

 💻 Paso 1: Clonar repositorio

 📂 Paso 2: Abrir en Android Studio

* Abrir proyecto
* Esperar Gradle Sync
* Conectar dispositivo físico

 ▶️ Paso de istalacion
* Presiona Run ▶
* Selecciona dispositivo Android
* La app se instala automáticamente


 🔐 Permisos importantes

La app necesita:

* 📡 Bluetooth (transferencias P2P)
* 🎤 Micrófono (control por voz)
* 🔐 Biometría (seguridad)
* 🔔 Notificaciones (alertas)
* 📱 Accesibilidad (modo sinestético)


 🧪 Prueba rápida 

1. Abre ANITRAX en 2 teléfonos
2. Activa Bluetooth en ambos
3. Selecciona “Enviar”
4. Ingresa monto en ETH
5. Confirma por voz o huella
6. Firma en MetaMask
7. Verifica en Sepolia Explorer



 ⚠️ Notas importantes

* Solo funciona en red Sepolia de prueba
* No usar con ETH real
* Bluetooth debe estar visible
* Permitir permisos en primer inicio
